# BES Viewer for Screen Reader

点字データ（.bes形式）を仮名に変換してブラウザに表示するツールです。

[このページから利用できます](https://BunYoshi.github.io/bes2kana-for-reader/)

第１カギや第１カッコ、点訳挿入符のような、開き記号と閉じ記号が同一の囲み記号をスムーズに確認することができます。

### 囲み記号の確認方法

- Shift + ↑／↓：　第１カギ（➂➅の点）で囲まれた範囲にフォーカスします（黄色）。
- Shift + →／←：　第１カギ（➂➅の点）で囲まれた範囲の末尾を拡張します。
- Ctrl + Shift + ↑／↓：　第１カッコや点訳挿入符（➁➂➄➅の点）で囲まれた範囲にフォーカスします（水色）。
- Ctrl + Shift + →／←：　第１カッコや点訳挿入符（➁➂➄➅の点）で囲まれた範囲の末尾を拡張します。


## 対応ファイルフォーマット

- **.bes**, **.besx**: 日本国内で広く利用されている「点字編集システム」などの標準的なバイナリ形式の点字ファイル。


## 主な機能

- **点字ファイルの読み込み**: `<input type="file">` 経由での `.bes`, `.besx` 点字ファイルの読み込み。
- **カナ表示**: 点字から日本語（カタカナ）への変換およびテキスト表示（ひらがな・カタカナを選択可能）
- **PWA（Progressive Web App）対応**: オフライン環境でもビューアを起動して利用可能。
